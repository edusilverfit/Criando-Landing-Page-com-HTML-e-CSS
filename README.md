# Criando Landing Page com HTML e CSS

Landing Page responsiva em HTML e CSS — desafio DIO Pro.

Projeto concluído no desafio "Criando Landing Page" da DIO Pro. Esta landing page foi construída com HTML semântico e CSS puro, focada em responsividade, boas práticas de estrutura e estilos (flexbox/grid, variáveis CSS, pseudo‑elementos). Inclui exemplos de componentes como header, e rodapé. Objetivos: praticar layout, acessibilidade básica e técnicas de truncamento.

# Tecnologias: 

HTML5; CSS3 (Flexbox, Grid, variables).

# Funcionalidades:

layout responsivo; imagens com object-fit; truncamento com text-overflow; animações com @keyframes.

# Como rodar:

abrir index.html no navegador; sem dependências.

# Aprendizado:

semântica HTML, posicionamento CSS, tratamento de imagens e responsividade.
